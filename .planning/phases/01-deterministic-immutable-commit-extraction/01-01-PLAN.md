  <name>Task 1: Define the three closed v1 artifact contracts and local diagnostic boundary</name>
  <files>integrations/vibery-station/package.json, integrations/vibery-station/schemas/station-evidence.schema.json, integrations/vibery-station/schemas/station-map.schema.json, integrations/vibery-station/schemas/station-extraction-receipt.schema.json, integrations/vibery-station/lib/contracts.mjs, integrations/vibery-station/lib/diagnostics.mjs</files>
  <action>
Create a native-ESM Node >=18 integration package with no dependencies, install hooks, host registration, or default-Archify entry point. Define strict schemas for exactly `station-evidence/v1`, `station-map/v1`, and `station-extraction-receipt/v1`; close every object against unknown properties and encode the patterns/enums/bounds established in research.

The evidence contract must carry one identity-derived Station canonical repository URL, full revision, tree OID, `sha1` object format, extractor profile/version and fixed limits, selected manifest records, package/workspace membership, exact package declarations by scope, and a mechanical analysis/fallback-reason section sufficient to explain an unsupported-but-integrity-valid shape. Contract tests must reject alternate transport spellings in artifacts even when they parse to the same repository identity. The map contract must carry snapshot/project, rooms, relations, and fallback state. The receipt contract must carry logical filenames and exact hashes/byte counts for evidence and map, repository revision/tree identity, contract/profile/limit versions, mode/counts, and diagnostics; it must not require or permit a self-hash, timestamp, duration, absolute path, branch, host, PID, Git version, or runtime version.

Implement strict runtime validation in `contracts.mjs` with stable `station-gate/schema-invalid` details. Keep schema documents and runtime closed-field checks in lockstep through tests; do not add AJV or another runtime dependency. Implement an integration-owned diagnostic factory/envelope using exactly `{code,severity,message,subject,evidence,supportedFixes}` without importing the process-global renderer diagnostic boundary.
  </action>
  <verify>
`node --test integrations/vibery-station/test/contracts-and-identity.test.mjs` passes contract fixtures that reject unknown properties, unsupported schema/profile versions, non-Station-canonical repository URLs, malformed IDs/OIDs/hashes, forbidden volatile fields, and a receipt self-hash.
  </verify>
  <done>All three versioned documents have strict schemas and importable zero-install validators, and failures use stable Station diagnostic envelopes.</done>

<task type="auto">
  <name>Task 2: Implement canonical UTF-8 bytes and versioned identity formulas</name>
  <files>integrations/vibery-station/lib/canonical-json.mjs, integrations/vibery-station/lib/identity.mjs, integrations/vibery-station/test/contracts-and-identity.test.mjs</files>
  <action>
Implement recursive object-key sorting with direct code-point comparison (`left < right` / `left > right`), preserving only domain-preordered arrays. Reject `undefined`, functions, symbols, bigint, non-finite numbers, sparse arrays, cycles, and non-plain/non-JSON values. Emit UTF-8 JSON with LF and exactly one trailing newline. Expose exact-byte SHA-256 helpers.

Implement the research formulas verbatim, using NUL separators and lowercase hex output:
- `project-` from `station-project/v1` plus canonical repository identity;
- `evidence-` from `station-evidence/v1`, `git-blob`, path, and Git OID;
- `room-` from `station-room/v1`, project ID, and structural key;
- `relation-` from `station-relation/v1`, declared-package-dependency, from-room ID, and to-room ID;
- `snapshot-` from `station-snapshot/v1`, project ID, revision, evidence SHA-256, and `node-workspaces/v1`.

Export explicit domain comparators for files (`path`, OID), packages (`root`, name), declarations (name, scope), rooms/relations (ID), evidence IDs, scopes, and fallback codes. Do not derive durable IDs from revision, labels, traversal index, layout, timestamps, or package display names.
  </action>
  <verify>
Run `node --test integrations/vibery-station/test/contracts-and-identity.test.mjs`; assertions compare exact buffers (including the sole trailing LF), permuted-object canonical equality, invalid-domain rejection, fixed hash vectors, and unchanged durable IDs when revision/labels/layout vary while snapshot ID changes with revision/evidence bytes.
  </verify>
  <done>Canonical bytes and every identity class are reproducible from explicit versioned inputs with no ambient or presentation data.</done>
