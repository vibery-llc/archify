Implement one private Git runner using `spawnSync('git', args, {encoding: null, shell: false, cwd, maxBuffer, env})`. Start from a minimal inherited environment with Git behavior forcibly overridden by `GIT_NO_REPLACE_OBJECTS=1`, `GIT_NO_LAZY_FETCH=1`, `GIT_OPTIONAL_LOCKS=0`, `GIT_TERMINAL_PROMPT=0`, `GIT_CONFIG_NOSYSTEM=1`, `LC_ALL=C`, and no pager; never permit caller overrides for these keys. Derive one Station canonical repository URL from the parsed identity: standard GitHub identities become lowercase-path `https://github.com/<owner>/<repo>`, standard Gitee identities become `https://gitee.com/<path>`, and identities whose transport/port/path-kind are semantically distinct retain the parser's normalized URL. Store and hash only that Station form, never caller/origin spelling. Map each failure to the stable `station-extract/*` codes researched for root, URL/origin, revision, object format, or unavailable objects.

Add an injectable process-runner seam used only by tests to assert exact commands/environment and to emulate missing objects without network. It must not be a provider/plugin surface.

<task type="auto">
  <name>Task 2: Enumerate and read bounded tree/blob objects without checkout influence</name>
  <files>integrations/vibery-station/lib/git-object-reader.mjs, integrations/vibery-station/test/helpers/git-fixture.mjs, integrations/vibery-station/test/git-object-reader.test.mjs</files>
  <action>
Enumerate exactly once with `git ls-tree -rz --full-tree <revision>` under a 16 MiB output ceiling. Parse Buffer records split on NUL; parse the fixed `<mode> <type> <oid>\t` header without first decoding the path. Reject missing terminators, malformed headers, invalid modes/types/OIDs, duplicate exact paths, and truncated/over-budget tree output as hard `station-extract/tree-*` failures because completeness is no longer provable.

Decode candidate path bytes with `TextDecoder('utf-8', {fatal:true})`, preserve valid Git path spelling, and classify (do not follow) invalid UTF-8, ASCII control characters, absolute/dot/parent/`.git` segments, case-fold collisions, and NFC collisions. Preserve tree mode/type so symlinks (`120000`), gitlinks (`160000`), trees, and regular blobs cannot be confused. The object reader returns complete sorted inventory plus unsupported-path classifications; it does not decide room topology.

Expose exact-OID `statBlob` and `readBlob` operations. `statBlob` uses only `git cat-file -s <oid>`, requires one canonical non-negative decimal size, and lets the evidence layer classify proven policy-size excess before reading. `readBlob` uses only `git cat-file blob <oid>`, returns a Buffer, and requires the caller to provide the exact previously probed size plus an integrity ceiling; absent/lazy objects, malformed size output, disagreement between probed and actual byte counts, or process-output overflow are typed hard failures. Fix resource constants at the researched contract values: 16 MiB tree output, 512 discovered `package.json` paths, 1 MiB per selected manifest, and 8 MiB total selected manifest bytes. Tree-output incompleteness and object unavailability are always hard failures; a sound exact size above a manifest policy budget remains an explicit evidence-layer fallback classification, never an attempted partial read.
  </action>
  <verify>
`node --test integrations/vibery-station/test/git-object-reader.test.mjs` covers spaces/tabs/newlines under `-z`, replacement refs, checked-out commit B while reading commit A, dirty/deleted/untracked checkout files, symlink and gitlink modes, invalid UTF-8/control paths, case/NFC collisions, malformed protocol, tree-output budgets, exact blob-size probes, probe/read disagreement, and locally missing objects. The fixture records `HEAD`, index bytes, and `git status --porcelain=v1 -z` before/after and proves no mutation.</verify>
  <done>The reader returns a complete bounded object inventory plus trustworthy exact blob sizes/bytes, or a typed hard integrity failure; policy-size fallback remains the evidence layer's explicit decision and checkout state is neither read nor changed.</done>
</task>
