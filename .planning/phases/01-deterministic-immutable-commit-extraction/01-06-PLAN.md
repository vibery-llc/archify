A bundle root contains immutable `generations/<generation-id>/station-evidence.json`, `station-map.json`, and `station-receipt.json` files plus one regular-file `CURRENT` pointer containing exactly `<generation-id>\n`. <task type="auto">
  <name>Task 2: Publish one immutable generation through a single atomic current pointer</name>
  <files>integrations/vibery-station/lib/station-output.mjs, integrations/vibery-station/test/station-output.test.mjs, integrations/vibery-station/test/station-cli.test.mjs</files>
  <action>
Resolve/canonicalize the bundle root, `generations` directory, candidate generation path, and `CURRENT` pointer using `canonicalFuturePath`/`pathsAlias`; reject aliases to protected inputs/staging paths, symlink components, non-directory bundle/generation roots, a non-regular `CURRENT`, invalid pointer bytes, path escapes, and an existing generation whose bytes do not exactly match the candidate. Capture physical parent identities and recheck every path immediately before publication.

Create one private same-parent staging generation. Write exact evidence/map/receipt Buffers with exclusive files; close and fsync files where supported; strict-validate/gate the supplied candidate bytes; fsync the staging directory; derive the deterministic generation ID from contract version and all three artifact hashes; then rename the complete directory once into `generations/<generation-id>` and fsync `generations`. If an identical immutable generation already exists, verify all bytes and reuse it; a conflicting generation is a hard failure.

Write `<generation-id>\n` to an exclusive same-parent temporary pointer, close/fsync it, perform a final identity/alias/type recheck, atomically rename that one regular file over `CURRENT`, and fsync the bundle root. That rename is the sole visibility commit. If interruption occurs before it, the old pointer remains authoritative; after it, the new complete immutable generation is authoritative. If bundle-root fsync reports failure after rename, atomically restore the previously captured pointer (or remove the new pointer when none existed), fsync again, and return `station-output/commit-failed`; if restoration fails, retain both immutable generations and all pointer-recovery material, return only `station-output/commit-rollback-failed`, and document deterministic manual recovery. Never delete prior generations in Phase 1, so readers that resolved the old pointer remain valid. Clean only non-authoritative temporary paths after successful bookkeeping; rollback-failure material is never removed.

Expose narrow injected filesystem operations and a pause/barrier seam for deterministic caught-failure, abrupt-child-process termination, startup inspection, and concurrent-reader tests. Production always uses the real local filesystem implementation. The startup/read helper must validate `CURRENT` once, resolve exactly one immutable generation, and reject malformed/missing/conflicting state rather than scanning for a newest directory.
  </action>
